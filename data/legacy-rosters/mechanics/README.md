# MFM 1.4 mechanics

Mechanics release input: the 140 rules of Warhammer 40,000 11th edition, MFM 1.4, that the [mechanic format](../../../docs/records.md) describes in full. Each summary is rendered from the record's fields. Each record translates structured fields from upstream data and carries its `attribution`. The same rules, with these fields as typed facts, are also in the [rule summaries](../rule-summaries/README.md).

They are pre-release drafts that no person has reviewed yet. [Mechanics releases](../../../docs/releases.md) explains how to build them.

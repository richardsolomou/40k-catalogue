# Pantheon of Woe pilot records

These four 11th-edition mechanics were reviewed against Necrons Faction Pack v1.3. They are the source records for the [v0.1.0 mechanics prerelease](https://github.com/richardsolomou/40k-catalogue/releases/tag/v0.1.0). The [pilot audit](../../../docs/necrons-coverage.md) records the covered rules and the consumer checks.

Each JSON file has its own source citation, structured mechanic and original summary. See the [quickstart](../../../README.md#use) for the packaged release or the [release guide](../../../docs/releases.md) to build an archive.

# VS Data documentation

## Releases

- [Mechanics releases](releases.md) explains how to verify an archive, find a rule and display its summary.
- [Catalogue releases](catalogue-releases.md) covers archives with multiple kinds of data and checks for upgrades.
- [Catalogue identity](catalogue-identity.md) explains rules versions, stable IDs, aliases and retired records.

## Data formats

| Data | Use it to |
| --- | --- |
| [Mechanic records](records.md) | Read triggers, conditions, targets and effects, then display a linked summary. |
| [Roster definitions](roster-definitions.md) | Build and validate army lists and wargear choices. |
| [Datasheet profiles](datasheet-profiles.md) | Look up characteristics, weapons, transport capacity and attachments. |
| [Points snapshots](points.md) | Price units and enhancements under a specific update. |
| [Localised names](localisation.md) | Display names and resolve imported lists to catalogue IDs. |
| [Rule summaries](rule-summaries.md) | Show a rule, FAQ or mission card in plain language with its links and official citations. |
| [Summary house style](summary-style.md) | Read or write a faction rule's summary in the one shape and phrasing every summary shares. |
| [Rule facts](rule-facts.md) | Read a rule's typed facts, such as Enhancement eligibility and award scoring. |
| [Mission packs](mission-packs.md) | Read mission setup, scoring windows and award values. |
| [Terrain geometry](terrain.md) | Place terrain, deployment zones and objectives. |
| [Faction marks](icons.md) | Use the original SVG marks in an app. |

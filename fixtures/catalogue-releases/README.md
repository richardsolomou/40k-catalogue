# Synthetic catalogue release inputs

Two catalogue release inputs for an invented catalogue, used by [test/catalogue-releases.test.ts](../../test/catalogue-releases.test.ts). Release `1.0` covers every roster, mission, and terrain entry. Release `1.1` renames a unit, merges a duplicate wargear entry into an alias, splits a roster option, retires a mission layout without a replacement, and adds a roster option and a terrain layout without records. Mechanics and points stay retained in both.

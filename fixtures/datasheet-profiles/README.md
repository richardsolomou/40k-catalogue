# Synthetic datasheet profiles

Profile records for the invented catalogue in [roster definitions](../roster-definitions/), used by [test/datasheet-profiles.test.ts](../../test/datasheet-profiles.test.ts). Each `identity.json` holds only the profile entries; the tests add them to the roster identity release of the same version. Version `1.1` changes a weapon's strength, splits one weapon profile into two firing modes, gives one attachment a conditional entry, gives a warden carrying a cinder cannon a larger base from a separately cited base size guide, and marks the Ember Colossus's base `unique`.

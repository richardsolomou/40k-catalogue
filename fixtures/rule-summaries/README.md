# Synthetic rule summaries

A catalogue release input for an invented faction, core rules and mission pack, used by [test/rule-summaries.test.ts](../../test/rule-summaries.test.ts). `rules-reference` holds a core rule and a numbered clarification under it, a weapon keyword, a core ability, an army rule with an interpretation flag and an attribution, a Stratagem with mechanic facts that names its Detachment (an entry of the retained `rosters` category), and an errata FAQ that amends the army rule and an unlisted detachment. Its identity also lists a retired FAQ with the publication that superseded it and an ability without a record. `mission-rules` holds a primary card, its award with typed facts, its action, and a twist.
